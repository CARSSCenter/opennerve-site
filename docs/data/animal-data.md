# Animal data

Preclinical (animal) datasets from CARSS consortium members, published on
the [SPARC Portal](https://sparc.science) (NIH SPARC's public data
repository). Each dataset below carries its own DOI, license, and full file
listing on SPARC — this page is a pointer and citation, not a mirror.

These are raw/processed research datasets, not evidence claims for a
specific OpenNerve component or hardware revision. If a component's
Evidence (E) level (`CLAUDE.md` §5) cites one of these datasets directly,
that citation belongs on the component's own page, linked back here.

## Acute stimulation and recording — rat sciatic nerve, cuff electrode

![Dataset banner: acute stimulation and recording of the rat sciatic nerve](https://assets.discover.pennsieve.io/dataset-assets/430/1/banner.png)

Electroneurography (ENG) and electromyography (EMG) recordings of compound
action potentials evoked by stimulation via a self-sizing, soft-closing
polymer cuff electrode.

- **Species:** Rat
- **Files:** 99 files, 367 MB
- **License:** CC-BY
- **DOI:** [10.26275/6fxa-8gef](https://doi.org/10.26275/6fxa-8gef)
- **Protocol:** [protocols.io/10.17504/protocols.io.q26g7m17qgwz](https://doi.org/10.17504/protocols.io.q26g7m17qgwz)
  (see also publication #6 in [Publications](publications.md))
- **SPARC dataset page:** [sparc.science/datasets/430](https://sparc.science/datasets/430)

**Citation:**
> Li, M., Elyahoodayan, S., Rezard, Q., Chen, J., Baldwin, A., Meng, E.,
> Song, D. (2025). *Acute stimulation and recording of the rat sciatic
> nerve using a self-sizing and soft closing polymer cuff electrode*
> (Version 1) [Dataset]. SPARC. https://doi.org/10.26275/6fxa-8gef

## Sacral stimulation and colonic multi-sensor recording — Yucatan minipig

![Dataset banner: sacral stimulation and colonic multi-sensor recording from Yucatan minipigs](https://assets.discover.pennsieve.io/dataset-assets/653/1/revisions/1/banner.png)

Electrophysiological and sensor data on the effects of sacral root
stimulation on colon motility. Sensor modalities include manometry, strain
sensing, electromyography, and electrochemical measurement of
neurotransmitters.

- **Species:** Yucatan minipig
- **Files:** 216 files, 2.08 GB
- **License:** CC-BY
- **DOI:** [10.26275/fqxr-szi4](https://doi.org/10.26275/fqxr-szi4)
- **Protocol:** [protocols.io/10.17504/protocols.io.36wgq14pxvk5](https://doi.org/10.17504/protocols.io.36wgq14pxvk5)
- **SPARC dataset page:** [sparc.science/datasets/653](https://sparc.science/datasets/653)

**Citation:**
> Baldwin, A., Larauche, M., Elyahoodayan, S., Huang, X., Abdelmonem, M.,
> Mousavi, M., Zhao, H., Mulugeta, M., Meng, E. (2026). *Sacral stimulation
> and colonic multi-sensor recording from Yucatan minipigs* (Version 1,
> Revision 1) [Dataset]. SPARC. https://doi.org/10.26275/fqxr-szi4

## About the images above

Both banner images are hotlinked directly from SPARC's own dataset-asset
host (`assets.discover.pennsieve.io`), at a URL pinned to that dataset's
specific version/revision — not downloaded into this repo. That keeps this
page from silently going stale if a dataset is revised, at the cost of this
page needing network access to SPARC's asset host to render the images
(consistent with how the PDF viewer already trades a commit-pin for
freshness on other pages — see `CLAUDE.md` §7).
