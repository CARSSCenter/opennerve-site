# How to contribute

OpenNerve accepts contributions across hardware, firmware, software, and
documentation. This page is a stub; it should route a contributor to the
right place rather than duplicate the specifics.

- **Hardware** (PCB, mechanical, lead, or sensor design changes): see
  [Hardware contributions](hardware.md) — currently a list of open questions,
  not a settled process. Read it before opening a hardware PR.
- **Firmware and software**: standard PR process against the relevant
  component repo (see [Components](../components/index.md) for repo links).
  Firmware and app repos are licensed CC-BY-4.0, same as hardware — see
  [Governance](governance.md) for the current licensing note.
- **Documentation**: pages under `Components` and `Software` in the nav are
  federated from each component's repo where noted; edit those upstream (the
  "Edit this page" link on each synced page points at the right repo). Pages
  authored directly in this repo (e.g. this one) can be edited here.
- **Questions or proposals that aren't yet a PR**: see
  [Community](../community/index.md) for how to start a discussion.

## What this page is missing

- A description of review turnaround and who reviews what (engineering leads
  per institution? a single maintainers group?) — depends on
  [Governance](governance.md), which is itself unsettled.
- Contribution guidelines specific to each repo type (firmware coding style,
  KiCad library conventions, etc.) beyond what's already in each repo's own
  README/CONTRIBUTING file, if one exists.
